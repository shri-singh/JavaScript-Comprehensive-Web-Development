# Contributing

Thank you for your interest in improving this course!

## How to Contribute

1. **Fork** this repository
2. Create a **feature branch**: `git checkout -b fix/chapter-04-typo`
3. Make your changes
4. Run `npm run lint && npm run format:check` to verify style
5. **Commit** with a clear message: `fix(ch-04): correct hoisting example`
6. Open a **Pull Request** against `main`

## What We Accept

- Typo and grammar fixes
- Improved explanations or examples
- New exercises (append to existing exercise list)
- Bug fixes in example code
- Accessibility improvements in HTML examples

## Style Guide

- Use ES2020+ syntax (`const`/`let`, arrow functions, template literals)
- Keep explanations concise — students learn by doing
- Every code snippet must be copy-paste runnable
- Follow the existing markdown template for chapter docs
- Run Prettier before committing

## Reporting Issues

Open an issue with:
- Chapter/file reference
- What you expected vs what you found
- Suggested fix (if any)
